# 录音质检工作区

工作区把三个日常流程放在同一个本机服务中：用固定规则批量检查录音；人工复核并积累问题、正常和漏检样本；用冻结的人工标准比较新旧规则，再明确选择日常版本。

## 启动和再次打开

首次启动时指定本人准备的录音目录、检测库和工作区目录：

```bash
voice-tools detect serve recordings/ --db qa-workspace/library.sqlite3 --out qa-workspace
```

打开终端给出的工作区地址，默认 `http://127.0.0.1:8766/workspace`。规则编辑器继续位于 `/editor.html`，旧的 `/` 入口也保留。再次启动可省略录音路径：

```bash
voice-tools detect serve --db qa-workspace/library.sqlite3 --out qa-workspace
```

目录、工作区名称、日常规则组合、检测历史和人工标准都保留在本机。省略路径时只恢复这个工作区曾明确指定的范围；网页不能任意浏览磁盘。服务仅监听回环地址。数据库和原始录音目录不作为网站资源公开。已有 1.0 检测库增加独立工作区表，不重写历史检测、规则或复核。

录音沿用 PCM16 WAV、单／双声道、8–48 kHz、最长 1 小时和 512 MiB 解码限制。其他格式先用 `audio prepare`。规则中的声道仍由操作者映射到真实角色；示例不等于已沉淀业务规则，原专项脚本仍需迁移并对照相同录音验证。

## 日常质检和直接复核

1. 在“编辑规则 / 复制新版本”导入或创建规则，并保存到检测库。
2. 在工作区勾选需要的已保存版本，点击“保存为日常规则组合”。同一定义只能选一个版本；不会隐式使用最新版本。
3. 选择“只检测新增”“全部重跑”或“小范围试跑”。试跑可勾选具体录音；未选择时按文件名取前 N 个，最多 100 个文件。
4. 批跑前重新扫描原授权目录。也可手动“重新扫描目录”。新增模式按录音 SHA-256 和所有所选配置摘要检查历史成功记录；规则变化、内容变化、失败或无窗口都不会被当作已经成功检测。
5. 在批次中打开复核，继续使用双轨波形、单轨、缩放、区间、循环与音量功能。确认问题、填写误报原因，或修正标签／时间后，点击“保存到检测库”。

在线保存将复核历史和相应人工标准放在同一个事务中；任一修订冲突或标准冲突都会整体拒绝，不覆盖别人的记录。刷新页面读取最新库状态。原有浏览器草稿可显式“将已有草稿保存到检测库”；静态报告仍保留草稿、导出、`review-import` 的离线流程。

每次批跑保存独立批次，工作区报告只包含该批数据。处理进度在页面显示；单个录音有错误或无可用窗口时显示部分完成。当前进度任务在本机进程内运行，服务关闭后不能自动续跑未完成批次；已提交的历史不丢失，重启后可用新增模式重跑尚未成功的组合。报告生成失败时已完成检测仍在库中，可使用 `detect report` 重新导出。运行中请保持服务开启。

## 未命中抽检和人工标准

“未命中抽检”仅列出检测成功且该配置零命中的录音。先选择并试听，再填写业务标签、检查起止秒数、复核人与判断原因：

- 发现漏检：在“补充漏检”保存问题片段；原始自动结果仍为零命中。
- 已检查无此问题：勾选已试听和检查，保存正常范围。这个结论只针对填写的标签和时间范围，不能扩大为整通录音完全正常。
- 命中复核：确认／修正形成问题标准；误报形成对应标签、范围的正常标准，误报原因必填。

工作区显示标准的录音名、标签、时间、复核人、原因与修订号。可修订或撤回，旧修订保留。相同录音、相同标签、重叠范围中的“问题”和“正常”冲突会拒绝；应先核对并修订／撤回旧结论。

离线复核历史仍独立保存；不会未经人工操作把全部旧结论自动转成标准。在线重开并确认所需结果即可积累标准。未命中但未人工检查的录音始终保留未知。

## 规则迭代

1. 在编辑器“复制为新版本”，修改指标或阈值并保存。旧版本不可覆盖。
2. 用工作区试跑确认规则行为，补充真实误报和漏检原因。
3. 在标准样本区按需要选择业务标签，填写名称并冻结当前人工标准。冻结记录包括录音摘要、标签、范围、结论和人工修订；之后修改样本不会改变旧样本集。
4. 选择固定集和同一定义的两个版本，运行对比。若样本集包含两个版本都不检查的标签，要求重新按标签冻结专用样本集。
5. 查看问题命中、漏检、正常范围误报、定位不匹配、未检查范围命中和正常范围正确排除数量，以及逐录音 JSON 明细。可下载带固定集摘要和配置摘要的完整对比。
6. 根据业务判断明确点击“将此新版本选为日常规则”，只替换该定义的日常版本，其他规则保持原值。对比不会自动切换版本；选择操作也不等于准确率通过认证。

比较将同标签的重叠片段合并，以交并比（IoU）至少 0.3 作一对一问题片段匹配。定位不符不会算作正确命中；命中正常范围记误报；未检查范围仍为未知，不据此推断总体准确率。整段累计规则的命中范围仍是其真实分析窗口，应使用与该语义一致的人工标准。

原录音缺失、内容变化、配置无法分析或没有窗口时，对比标为不完整，失败项不进入汇总。可比较部分的数字不能代表完整固定集。调参集上的改善也不等于未见业务录音上的效果，建议另保留未参与调参的验收集。

原 CLI 的 `detect compare` 继续按两个历史批次比较；工作区固定集比较是独立能力，不改变旧命令的统计语义。
