## 已知限制和未执行的验证

- 没有用户实例地址／凭据，未进行线上登录、真实通话查询或真实导出对照。
- 没有启动完整 HOMER／PostgreSQL／captagent 环境；未测试 HEP 入库和线上分片场景。
- 没有测试所有 HOMER 7 历史版本、定制字段、外部 SSO 或反向代理配置。
- 本次确认 TLS 客户端配置默认开启验证，未对用户私有 CA 或真实 HTTPS 服务做部署验收。
- Python 3.9 进行了语法检查；运行测试使用 3.12.14，未在 3.9／3.10／3.11／Windows／macOS 上执行完整套件。

- 无法通过 HOMER 重建 PCAP 证明真实 IP 分片；分析程序明确保留 `unknown`。
