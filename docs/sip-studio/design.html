01 / EVIDENCE & DECISIONS

借鉴交互，保留轻量执行链路。

核对官方公开文档和固定提交的 GitHub 仓库；以下是对当前项目的适配判断，未安装这些平台做性能比较。

产品官方资料确认了什么用于本项目的设计取舍
XSwitch外呼任务、放音/路由、状态与挂机原因；媒体、录音与 SIP 诊断用例、素材、环境、结果分区；保留通话证据完整通信平台较重；xswitch-free 镜像不证明完整编辑器源码开源
Node-RED节点库、工作区、侧栏、可复用 subflow；Apache-2.0左侧步骤插件，右侧参数；模板复用当前顺序 CLI 不需要任意连线与通用消息流
Jambonz / Node-REDplay/dtmf/gather/hangup 等电话节点；运行栈包含 Drachtio、FreeSWITCH、数据库让每个节点表达一个明确电话动作借鉴动作组织，不引入其执行栈；节点包授权另核查
Twilio StudioWidget Inspector、草稿测试、流程导入导出草稿与运行分离；可见校验与参数侧栏商业 UX 参考，不是免费开源自托管方案
Restcomm RVD历史可视化电话项目，AGPL-3.0；最后推送元数据为 2018 年领域参考不以其为基础；当前可运行性未验证
React Flow自定义节点和连线 UI 库，核心 MIT留作未来分支编排候选不是 SIP 引擎；当前顺序列表用原生拖放即可
XSwitch 文档中的“菜单管理”是后台导航配置，“SIP 流程图”是报文诊断。本轮没有足够公开证据确认其完整拖拽编辑器及源码许可证，不将这两者当作业务编排证据。

01 / REUSE

用例、环境、素材分别管理

一个用例可以更换目标环境；同一素材可插入多个用例。导出时固化当前环境参数。

02 / VERIFY

字段通过 ≠ 实际执行通过

未知媒体时长显示待确认。RX 录音是通话级配置，界面不制造执行器不存在的动作。

03 / PORTABLE

两种导出，各有用途

Studio 草稿保留名称、标签和节点信息；scenario.json 只保留 CLI 严格支持的字段。

03 / KEEP ONE SIP ENGINE

前端管编排，CLI 管通话。

本地 HTML 编辑器→scenario.json→voice-tools sip→PJSUA2 / UDP→你的网关

当前通过文件导出连接。下一阶段添加本地 Python API、串行队列、SSE 与取消处理，继续使用原 CLI 子进程；不另建 FreeSWITCH/ESL 执行服务。

voice-tools --json sip validate scenario.json
voice-tools --json sip run scenario.json --dry-run --out outputs/plan-001

以上都是离线校验。文件选择不会复制素材；WAV 与 media.json 请按相对路径放置。真实拨测在 CLI 中另行执行。

素材证据

实际 WAV 样本生成波形，支持试听。PCAP 先明确单方向/SSRC，再由 CLI 转成音频与按键。

运行证据

未来展示 result、events、rx.wav；tx_source.wav 始终说明为播放源重建，不当作远端接收证据。

扩展边界

声明式插件 + 参数 schema + 显式编译器。分支或 ASR 必须先有执行器能力，再开放界面。

05 / ACCEPTANCE CASES

以实际造用例的路径验收。

检查用例说明和最终结果见 完整验收记录；这里列出重点操作及预期。

编号 / 场景操作应看到什么
U01 步骤编排拖入等待、拖动卡片，撤销/重做次序、序号与 JSON 一致；挂断始终最后
U02 连续编辑连续修改名称、DTMF、方式、时长和间隔不丢焦点操作；卡片、预算与导出同步
U03 用例管理复制、改名、按标签搜索、删除、恢复副本独立；搜索结果真实隐藏；删除可撤销
U04 导入导出下载两种 JSON，再导入；导入含 password 的错误文件保持执行语义；错误导入不覆盖原用例
U05 环境复用添加本机测试环境并用于当前用例目标、编解码器及端口随导出更新；不拨号
U06 WAV 素材分别选择 8 kHz 和错误格式 WAV，试听有效素材真实波形/播放；错误格式拒绝；刷新后需重选音频
U07 PCAP 媒体登记有 DTMF 的 media.json事件数量正确，引用音频和哈希仍标记待 CLI 校验
U08 失败与恢复无效按键、预算超限、损坏存档阻止无效执行文件；保留最近有效草稿/原始存档
U09 手机编排375 px 下点击插件、↑ ↓ 排序、进入参数和页面导航无需拖拽也可完成；没有横向溢出
U10 执行边界预演并查看运行记录明确无呼叫/无录音，真实历史为空
C01 编译兼容JS 导出全部支持动作、环境、最小输入和往返草稿实际 Python CLI validate 与 dry-run 接受
C02 文件边界让导出引用不存在的音频CLI 返回输入错误，浏览器字段检查不冒充文件验证
本轮没有重跑 SIP 网关或公网呼叫。主分支的历史互通与最新 Baresip 未通过项保留在各自报告中，不计入本原型的“通过”结果。
