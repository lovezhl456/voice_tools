## 深度检查中修复的问题

1. **与最新 main 对齐**：媒体 `end_observed` 必须是 boolean；相邻 DTMF 浮点边界容差一致。JS 的显式 null 不再被 `??` 偷换成缺省值；非字符串 action 不能经对象键强制转换绕过检查。
2. **连续参数编辑**：字段提交只更新画布与预算，不整页替换正在编辑的侧栏，避免下一个点击目标消失。
3. **可恢复存储**：无效参数不覆盖最近有效草稿；损坏 JSON 保留原文；读权限关闭与存档损坏区分处理，避免“下载原始存档”再次读取不可访问的存储。
4. **导入与界面一致性**：环境配置不能夹带另一个 steps/schema_version；素材时长必须与节点类型对应；复制名称及自动生成素材名称限制长度。
5. **搜索可见性**：显式 `[hidden]` 样式防止卡片的 flex 布局覆盖搜索隐藏状态。

未通过的早期测试与修复后的结果保存在本机工作记录中；上述表格描述最终状态。浏览器文件选择第一次使用工具内的事件回调导致测试工具残留 modal 状态，随后仅重启本任务独立会话并用真实 file input 重新完成整组测试；不是以未返回结果的旧脚本作为通过证据。
