# 在页面中定义指标和业务标签

0.17.2 补齐配置编辑界面。进入逐轮 QA 复核页、整通复核页或 detect 报告，点击 **“定义指标与标签”**，可通过表单创建检测配置。原复核、波形和人工标注功能继续保留。

页面可编辑配置名称／标识／版本、声道、分析起止与跳过范围、排除时段、整段／滑动／活动结束窗口、多个指标及其参数、AND／OR／NOT 嵌套条件、排除条件和输出业务标签。条件通过指标标识关联；重命名指标会更新引用，仍被规则引用的指标不能直接删除。

## 本机保存并运行

要从页面直接保存版本和运行检测，先启动本机配置服务。录音范围在启动时明确指定，页面显示这一列表：

```bash
voice-tools detect serve recordings/ --db detection.sqlite3 --out editor-workspace --port 8766
```

打开终端打印的本机地址（默认 `http://127.0.0.1:8766/`），完成以下操作：

1. 点击“新建配置”，或从已保存配置／示例开始。
2. 设置指标。例如右轨的累计静音时长，阈值 -45 dBFS，最短片段 0.1 秒。
3. 在“判断条件与输出标签”中填写标签，例如 `AI无声`，设置累计静音时长大于等于 2 秒；需要时添加其他比较、条件组或排除条件。
4. 点击“检查配置”，再“保存到检测库”。同标识、同版本的不同内容会被拒绝；修改已有配置时使用新版本号，或“复制为新版本”。
5. 在“运行检测”选择一个或多个已保存的版本，点击“运行检测并生成报告”。
6. 点击运行结果中的报告链接，按业务标签检索并试听。通过报告里的“定义指标与标签”可以返回配置服务继续调整。

新建、选择示例、导入和复制均产生未保存草稿，保存前禁止运行。放弃修改只恢复已保存的配置；还没有已保存版本时，回到尚未保存的初始示例，仍不能运行。刷新页面可恢复草稿，旧格式草稿中的未入库内容不会被当成已保存版本。同一定义在单次运行中只选一个版本；保存新版时会取消该定义旧版本的运行选中状态。每次运行生成新批次；既有检测和人工历史不会被覆盖。部分录音出错或缺少完整窗口时，页面明确显示处理错误／无窗口数量，报告保留原因。

关闭终端或按 Ctrl+C 停止服务后，数据库和已生成报告仍保留。使用同一个 `--db` 和 `--out` 重启可继续编辑；`--out` 必须为空目录或属于同一个检测库的既有服务目录。`--out` 与输入目录不能重叠，也不能包含输入录音；服务按真实路径检查符号链接，避免重启时把报告音频重新当作输入。数据库可以位于空工作目录内，例如 `--db editor-workspace/library.sqlite3 --out editor-workspace`，但不能放在公开的 `reports/` 子目录或使用 `.library.json` 标记路径。目录检查在创建数据库之前完成。`--port 0` 可使用系统分配的空闲端口。机器启动可用 `voice-tools --json detect serve ...`，首条 JSON 返回 `status: listening` 和访问地址，进程持续运行。

服务仅监听 `127.0.0.1`。页面操作复用现有 Python 配置校验、SQLite 历史库和检测引擎，不在浏览器另算一套规则。网页请求不能指定额外录音路径、数据库或任意输出路径；写操作校验本机 Host、Origin 和随机会话标识，不提供跨站访问。服务只返回生成的报告及其试听副本，不直接暴露数据库或原始输入目录。

## 离线配置和导入导出

静态报告旁边自动生成 `config.html`。这个页面无需服务就能配置和导出；也可以单独生成：

```bash
voice-tools detect config-ui --out config.html
```

离线页面明确显示“离线配置页”，按钮为“保存到浏览器”，不声称已写入检测库或执行检测。配置可从 JSON 导入，也可下载为现有 1.0 格式，再由 CLI 使用：

```bash
voice-tools detect config-check custom-rule@1.json
voice-tools detect config-add custom-rule@1.json --db detection.sqlite3
voice-tools detect run recordings/ --definition custom-rule@1 --db detection.sqlite3
```

已保存浏览器版本与未保存草稿分别存储。重新打开页面可恢复草稿，未保存内容不会静默替换为其他配置；需要先保存或明确放弃修改。下载 JSON 不等于保存版本。浏览器禁止本地存储时会提示，可下载配置文件保存。

导入会保留既有窗口、指标参数、全部组合条件和排除规则，拒绝未知字段、重复 JSON 键、无效指标引用、过深条件和非法数值。客户端使用同一份公开 Schema 作表单校验；本机保存／执行仍以 Python 校验为准。完整格式、指标定义及计算语义见[检测规则手册](detection-rules.md)。

示例配置仍只是格式示例，未获得原专项脚本，不代表脚本迁移一致性或真实业务录音准确率已经通过验证。
