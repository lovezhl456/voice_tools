## 必须拒绝的情况

- 未知字段／指标／参数、非法声道、非有限数字、错误引用、重复规则 id、过深／过多条件、无效窗口。
- 同 id/version 内容变更、重复 batch_id；原结果和人工历史不被覆盖。
- 缺失右声道、WAV 损坏／截断、完整窗口不足、分析全部排除。保存 error/no_windows 或输入错误，退出 3，不能当作阴性或自动通过。
- 复核库身份错误、旧修订、重复补标、非法片段、未知结果、标签修正却使用非 corrected 状态；事务整体回滚。
- 源音频摘要改变或不可读：不复制新内容冒充原音频，保留波形证据、关闭试听，带音频报告返回部分错误。
- HTML 标签作为文本展示；CSV 公式类文本加前导单引号；检测定义不执行 Python/JavaScript。
- 比较中一侧未执行／出错／无窗口，不能当作另一版本消除了问题；人工正反结论冲突不计入误报／漏报改进。

以上均由新建的 30 项 Python 测试或 D01–D05 浏览器反例覆盖。现有 HOMER 无 site-packages 启动用例还防止新工具注册提前加载 NumPy。

## 本轮发现及修复

1. 初轮全量发现新指标模块在注册 detect 时导入 NumPy，破坏 HOMER 的无第三方依赖启动。改为实际计算时延迟导入；45 项相关用例和最终全量通过。
2. 手机截图发现候选按钮被 flex 压缩后文字重叠。禁止按钮收缩，并在桌面／手机 D02 增加高度断言；重验通过。
3. 本机旧 Python 3.9 环境缺 wheel 构建工具；改用已经存在的完整 Python 3.12 验收环境，没有修改全局依赖。初次浏览器缓存路径未指定，后续复用已有固定版本缓存；原失败日志保留。
4. 收尾补充批次中每个配置的错误明细、按录音和片段起点排序及公共退出码描述；对冻结代码重新运行上述最终全量和安装包验收。
