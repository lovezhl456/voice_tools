## 必须拒绝的情况

- 未知字段（包括 `__proto__`、`constructor`）、错误指标引用、重复 JSON 键、非法数值、空条件或超出深度／节点上限。
- 同定义版本不同内容，重复运行批次；表单未保存时运行已存旧版本。
- 外站 Origin、错误 Host／会话标识、非 JSON 请求、超过 1 MiB 的请求及浏览器上传；API 不接收录音路径／任意输出路径。
- 请求数据库、输入目录、目录穿越或含空字符路径。只允许访问生成报告和它的音频副本，并支持合法 HTTP Range。
- 删除被条件引用的指标；导入失败不能替换当前表单；生成报告失败不能留下一条已完成批次。

JSON 解析复用现有严格解析器；服务绑定 `127.0.0.1`，不改变代理、nginx、持久权限或用户环境。前端校验用于及时提示，保存和执行仍由 Python 决定。

### 实际本地示例的证据边界

用户原有20个合成文件的 QA 报告重新生成为0.17.2，仍为19个应答机会、11个候选、0个 QA 处理错误。旧报告保留，人工标签未自动迁移。原 URL、社区参考、离线编辑和原有静态报告入口保留。

配置服务使用相同20个文件。按既有 detect 内容摘要规则去重后为14份独立音频；通过页面保存 `ai-silence@example-1` 并运行，生成8条 AI无声 标签，1份缺少所配置声道的样本记为 error，2份没有完整窗口／触发活动的样本记为 no_windows。页面显示部分分析，未把这些样本记为正常。结果标签筛选、实际音频播放、保存后重新选择和手机端配置检查均通过；没有写入人工确认。页面功能无 JavaScript 错误，检测报告沿用的 favicon 缺省请求返回404，不影响业务资源。
