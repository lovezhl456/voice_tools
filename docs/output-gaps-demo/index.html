时间轴复核 · 跨机任务复查 · 检测报告

四类候选

长停顿 ≥800 ms；短断音 50–300 ms；1.5 秒内至少 3 次短断音；已有输出和明确继续播放预期时的中断候选。

首次不回答或应答延迟继续使用 QA。无候选不能解释为通话通过。

先核实，再排除

确认声道角色和时间映射后，工具合法等待、用户插话、TTS 完成与取消才参与过滤。证据冲突保留声学候选。

到包间隔与音质分段提供线索，不自动认定网络、TTS 或模型故障。

单独 CLI 就能使用

voice-tools gaps analyze call.wav \
  --out outputs/gaps --include-audio
voice-tools --json gaps analyze calls/ \
  --evidence evidence.json --out outputs/gaps-linked
voice-tools gaps review-check review.csv \
  --results outputs/gaps/results.jsonl
voice-tools schema --tool gaps

从候选列表选择区间，切换双轨或单轨试听；记录判断、补标漏检，再导出 CSV。旧 QA 标签与间隙标签保持独立。
