基线 `8b05129`，分支 `feat/v0.18.1-review-workspace`。目标为目录质检、人工复核积累、规则迭代三个连续流程；真实规则迁移与业务准确率需原脚本和实际录音，不能以合成样本替代。

| 能力 | 处理 | 验证 |

## 拒绝条件

- 草稿/未知规则、重复定义版本、录音摘要变化、越过授权目录、服务输出混入输入。
- 复核修订冲突、跨库记录、无效范围、误报原因缺失；不覆盖历史人工结论。
- 未试听/未标注不推定正常；正常样本与问题片段冲突；检测失败和无窗口不算通过。
- 固定集为空、比较版本不同定义、缺失音频/部分失败、只减少命中不推断改进；不自动启用新规则。

## 验证与交付

先 detect 与 CLI 相关测试，再一次最终 Python discovery、Node、CLI 兼容。安装 wheel 执行原 R/D/E 验收及新增工作区完整桌面/手机流程；保留脚本、夹具和证据。最终差异执行 code-readability、深度边界检查，独立分支推送并创建 PR，不自动合并。
