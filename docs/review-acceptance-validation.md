## 失败与反例确实会被发现

首轮 16 项中 12 项通过，R02 点击定位、R03 区间播放在两种视口失败。原因是测试服务器没有实现音频字节范围请求；生产静态服务已有该能力。为测试服务器增加真实的单范围 206／416、后缀范围与 HEAD 支持，并用 3 个 HTTP 测试验证。保留原浏览器断言，选测 4 项与最终完整 16 项均通过；没有修改产品逻辑或跳过断言。

另外复制最终生成的夹具，在副本 `main/report.html` 注入 `#waveform { display: none !important; }`，用同一 Playwright 配置执行桌面 R02。结果为 1 项失败、退出码 1，报波形不可见，保留失败截图与 trace；原始报告未改变。该实验验证了缺失波形会被自动发现。
