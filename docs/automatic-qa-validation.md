# 0.16.1 整通自动质检验收

基线 `a255ee5`，原判定代码提交 `de898f8`，分支 `feat/v0.16.1-autoqa`；[PR #32](https://github.com/lovezhl456/voice_tools/pull/32) 待审阅。实现覆盖工程规则、固定本地语音模型、整通结论、人工例外／抽检及任务结果迁移。下方先记录原整通流程验收；后续基于 `4c25846` 的 CLI 安装器增量与最终回归另列于文末。

## 模型与受控素材

- 固定 [Silero VAD 6.2.2](https://github.com/snakers4/silero-vad/tree/60b7ffa243625ebdc1070275a29f18c87843786a) 官方提交及 Git blob；ONNX SHA-256 为 `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`，大小 2,327,524 字节。产品 `model-download` 实际下载校验通过，doctor 真实 CPU 推理通过，MIT 许可原文随包保留。
- 独立模型环境：Python 3.12.14、NumPy 2.5.3、ONNX Runtime 1.30.0、SciPy 1.18.1。显式 CPU provider、禁用运行库遥测；源码流水线和任务执行在 macOS `sandbox-exec` 禁网条件下运行。
- 本机中文系统语音构造 7 个初始双轨场景：正常 → 自动通过；无应答、迟答、插入长间隙 → 自动异常；纯音代替回答、录音截断、声道未核实 → 待复核。均完成模型推理，无处理错误。14 个声学机会合并为 7 个模型轮次、7 条整通记录。
- 补充第 8 种正常双轮中文对话，中间等待用户 3 秒。模型识别为两个正常轮次，排除旧工程规则产生的轮次间停顿疑点；独立回归确认这一排除不会隐藏真正的迟答。
- 最终安装 wheel 后重新处理全部 8 种场景：2 自动通过、3 自动异常、3 待复核，无处理错误。集合刻意包含大量异常，不能将其比例外推为真实业务效果；语音模型不验证中文回答语义。
