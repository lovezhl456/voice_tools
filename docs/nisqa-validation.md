# NISQA 本地验收记录

验收日期：2026-09-20。目标版本 `0.10.1`，开发分支 `feat/v0.10.1-nisqa`，从 `origin/main` 的 `d44599c` 创建，最终验收前已合入主线 `374456f`（SIP 批量 PR #16）。本记录验证下载、安装、离线真实模型执行和 CLI 行为，**不代表人工听感准确度或生产通话验收**。安装和使用步骤见 [NISQA 手册](nisqa.md)。

## 已通过的验证

- 由 `voice-tools nisqa download --model-dir .local/nisqa-model` 实际下载官方固定版本权重，大小和 SHA-256 一致；`doctor` 的依赖元数据及权重检查通过。
- 安装后通过 `scripts/nisqa_smoke.py` 调用 CLI，真实权重完成短素材的 3 段评分，以及持续执行素材的 29 段评分；两次均无证据不足和处理错误。
- 真实模型对齐测试禁用 urllib、requests 和 TorchMetrics 的权重下载入口，本工具与 TorchMetrics 1.9.0 公共函数的五项输出在 `rtol=1e-6, atol=1e-6` 内一致，随后完成服务层整文件处理。此测试用于发现封装或分数顺序错误。
- 合入最新主线后的完整仓库测试：`337` 项，`317` 项执行通过、`20` 项跳过，耗时 `54.477` 秒。跳过的是 `19` 项未启用的原生 PJSUA2 本机 SIP 集成测试和 `1` 项未安装的可选 WebRTC VAD 测试；本轮真实 NISQA 对齐测试已启用且通过。
- NISQA 失败路径覆盖权重损坏/超长下载/网络失败/符号链接、缺少依赖、输出目录保护、双声道显式选择、单声道不复制、静音/低能量/短段/空文件、损坏音频、不支持采样率、非有限音频/分数，以及片段失败后继续处理。
- 构建 wheel 后，在仅含 NumPy 和 voice-tools 的独立环境中、源码目录之外验证版本、帮助、schema 和 `doctor`。缺少可选依赖时 `doctor` 返回退出码 `1`；schema 不加载 torch、torchmetrics、librosa、soundfile。wheel 包含 NISQA 的 5 个 Python 模块，不含权重、录音或虚拟环境。

全仓测试可复现命令（需自行准备本地权重及语音）：

```bash
VOICE_TOOLS_NISQA_MODEL_DIR="$PWD/.local/nisqa-model" \
VOICE_TOOLS_NISQA_AUDIO="$PWD/data/speech.wav" \
python -m unittest discover -s tests -v
```

原生 SIP 与 WebRTC VAD 是否运行，仍取决于对应依赖和环境开关，不能仅凭总测试数推断其已验收。

## 资源实测

干净的后续测量在回归测试结束后单独执行，使用默认 10 秒窗口、2 线程，命令如下：

```bash
python scripts/nisqa_smoke.py .local/nisqa-repeat.wav \
  --model-dir .local/nisqa-model --out outputs/nisqa-timing-001
```

| 指标 | 结果 |
|---|---:|
| 输入语音时长 | 286.017 秒 |
| 已评分片段 | 29 |
| 总墙钟耗时，包含 Python 启动 | 3.808 秒 |
| CLI 内部总耗时，包含运行库/模型加载 | 3.378 秒 |
| 运行库和模型加载耗时 | 1.279 秒 |
| 文件读取、前处理、推理及逐段输出耗时 | 2.099 秒 |
| 子进程峰值 RSS | 480.563 MiB |
| 内部总耗时 / 已评分音频时长 | 0.011810 |

上述是新 CLI 进程的一次后续运行；此前已经执行过模型，**库/JIT/文件缓存已预热**，不是新装机器的首次启动。素材只是同一段合成语音重复，结果不能外推到不同采样率、双声道、大量短文件或真实通话的整批吞吐。

首次执行短素材时，包含初始化并且与回归测试并行，墙钟耗时为 15.456 秒、峰值 RSS 为 616.828 MiB。这一结果有并发干扰，仅说明启动成本可能明显不同，不用它做独立性能基准。

峰值 RSS 是进程实测占用，不是系统最低内存要求，未包含操作系统和其他服务。Linux 的 4 vCPU / 8 GB 建议是起步验证预算，尚未测量。批量部署应在目标服务器上，用自己的代表性录音测量耗时、峰值内存和失败比例，再决定并发数。

- 真实中文通话与人工评分的一致性、合格阈值、录制点差异、生产吞吐和长时间稳定性。
- 模型的商业使用许可：官方权重含 CC BY-NC-SA 4.0 非商业限制，本地运行成功不等于获得商业授权。

后续验收应使用有使用权限的真实通话，按录制配置分别评估声道，并保留采样率、分段策略和人工复听结论。RMS 门槛不是人声检测，模型高分也不能替代既有无声/延迟规则。
