# 0.19.1 多 Tab HTML 工作台实施计划

基线 `e773ef7`；分支 `feat/v0.19.1-tabbed-workbench`。用户要求仓库后续生成的 HTML 也提供统一多 Tab 入口。

新增 `voice-tools workbench build`，接受明确指定的本地已生成报告目录。统一导出 `index.html`，五个固定 Tab 为检测与复核、整通质检、输出间隙、跨主机任务、使用说明。未提供的业务报告显示空状态；默认离线生成任务编排及用法说明。完整复制报告子目录及资源，使用相对地址，离线可打开，也可整体移动后通过任意本地 HTTP 路径浏览。构建不运行分析、模型或呼叫。

| 受影响能力 | 决定 | 验证入口 |
| --- | --- | --- |
| 原分析、复核、编辑、任务 CLI 与 HTML 地址 | 保留；统一导出为新增入口，不替换单页合同 | 默认全量与原安装包浏览器 E2E |
| 音频、JSON、CSV、配置、复核导入导出 | 完整复制，子页相对路径保持 | 安装包 CLI 生成→浏览器导出→CLI 导入→重开 |
| 当前输入、滚动、页面历史 | 切 Tab 保留 iframe；离开时暂停音视频 | 桌面/手机状态保留、音频和浏览器导航 |
| 网页可搬移、直接打开 | 相对路径；file 模式不依赖 fetch 或外站 | 输出目录搬移后 HTTP 与 file 页面检查 |
| 缺失报告 | 明确空状态，不伪造检测结果 | 空导出与错误参数 E2E |
| 任务包内 HTML 不执行 | 保留；本命令只接受用户指定的本地导出目录，不读取 zip | 原任务回归；新命令不进入任务 catalog |

必须拒绝：缺少入口文件、错误输入类型、符号链接/特殊文件、输出覆盖非空目录、输入输出互相包含。失败不得报告 completed；参数拒绝发生在输出修改前。页面加载失败可重试，不把错误页算正常加载。标题/路径等参数不得注入脚本。未提供数据与有报告分别说明。

验证：沿用安装 wheel 的 `check_review.py` 和 `check_detection.py`。后者加入 H01–H04 桌面/手机 E2E，从真实 CLI 生成并搬移多 Tab 输出，检查本地资源、检测复核/任务导出再打开、file 模式、输入失败拒绝与加载恢复；产物含 CLI 记录、导出文件、截图、安装来源与结果。此任务不新增单元测试。最终执行默认全量 Python、Node、CLI 兼容及安装包浏览器；关闭真实模型/原生回环开关。

计划自检第 1 轮：补入目录搬移、file 协议、未配置 Tab 和不进入任务 catalog 的边界，避免仅复刻固定 8080 外壳。第 2 轮：检查目标、旧能力、依赖、文档和交付，无未解决项。按仓库 PR 模板交付，合并仍需用户授权。

## PR #41 两项 review 修复（2026-09-27）

范围仍属未合并的 0.19.1。修复前已确认：Python 3.9 的 argparse 将 `nargs='*'` 位置参数标为 required，而 3.12 标为 optional；公开 schema 和快照因此不一致。工作台从 localStorage 恢复非首个标签但 URL 无 hash 时，切换后后退会错误回到首个标签。

保留能力：必填位置参数和显式必填选项保持必填；`detect serve` 首次启动与省略输入恢复均保持原行为；显式 Tab hash、刷新和前进后退兼容。修复按位置参数语义导出 required；初始化恢复标签时使用 replaceState 规范无 hash 历史项，不增加多余历史记录。

回归先补 E2E：W05 从安装包 CLI 读取 schema，对照快照，用真实服务首次启动/保存后省略 inputs 重启，在浏览器确认目录与日常规则恢复；H01 加入先保存使用说明、无 hash 重开、切换、后退/前进场景。先在旧 wheel 确認这两个用例会失败，再修产品代码。另对 Python 3.9/3.12 的完整 schema 做实际 CLI 导出比较。最终重建 wheel、执行默认全量。无新增单元测试。

计划自检：第 1 轮补入 Python 版本差异回归与服务真正重启，避免只改快照或只测带 hash 的页面。第 2 轮检查旧能力、失败路径、证据、文档和 PR 交付，无未解决项。
