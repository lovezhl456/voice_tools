# 0.16.2 整通复核波形验收

2026-09-22，基线 `08f861b`，分支 `fix/v0.16.2-assessment-waveform`。修复整通复核页未接入原有波形辅助的问题；旧逐轮页组件一直存在。

## 实现边界

- 复用本地打包的 WaveSurfer 7.12.12、共享波形与播放器；旧波形面板和控制区提为共享 HTML/CSS，避免两套样式和播放逻辑。
- 原始双轨幅度、同一时间轴、缩放与显示增益；已核实的用户／AI 角色、未知角色和单声道分别提示。图形增益不改变音量。
- 建议复核范围固定显示，试听边界可拖动／键盘调整；支持范围聚焦、循环、到点暂停和单轨试听。证据按钮同步图形范围与播放器。
- 每轨最多 1200 格 min/max 摘要随结果保存；无需复制音频也可看波形。校验声道、格数、有限幅度和时长覆盖，拒绝无效导入数据。旧无摘要结果继续显示提示并保留试听。
- 不改变 `qa-assessment-2`、判定策略、结果身份或整通标签合同，不增加逐片段必填项。
